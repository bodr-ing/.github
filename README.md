# .github

Shared defaults for every repo in [bodr-ing](https://github.com/bodr-ing):

- `profile/README.md`: the public org page
- `ISSUE_TEMPLATE/`, `pull_request_template.md`: default templates for repos that have none of their own
- `CONTRIBUTING.md`, `SECURITY.md`: shared rules
- `workflow-templates/gitleaks.yml`: secret scan workflow, offered under Actions → New workflow in every repo
